without modifying its frozen tools, the ordinary observer, original sources or

blocked. Two bounded metadata observations and one private COFF projection have
completed. The derived object passed independent artifact review; it has not
been archived, linked or executed.

## Pure observer contract

`parent_eh_adapter.observe_parent(raw, contract, recipe, unit_proof, recipes,
reference, original_highlow_sites, executable_ranges)` consumes a central
singleton contract and exact authoritative unit context. This pure API does not
authenticate arbitrary caller claims; the collector pins and reconstructs actual
inputs. It returns either a structural candidate or explicit blockers, preserving
all false runtime/provider/ABI/link/namespace/frame/layout flags.

The observer requires the native object/source/recipe and exact verified parent
joins; complete original field evidence; all selected native EH pieces MATCH;
whole no-duplicates parent COMDAT; exact parent-owned associative code/state;
local handler/FuncInfo/unwind-map identity; and complete symbol-cut coverage.
Unchanged ordinary and EH comparisons replay with comparison-only recipe/global
bindings. Per-piece original mapping supports noncontiguous helper placement.
Partial or identical overlapping original intervals are rejected by this initial
policy; no nearest-address or contiguous-anchor assumption is used.

The supported family is VC9 EH3 FuncInfo magic 19930522, one to sixty-four states,
flags 1 and zero catch/try/IP/exception-spec fields. Entire unwind-map plus
FuncInfo extent must be exactly 8*n+36 bytes, with either descriptor ordering
permitted only when the two exact intervals are disjoint and cover the section
without gaps or padding. Every transition targets -1 or a
strictly earlier state. Explicit no-action states require original/native zero
and no relocation; action states require one pointer to a complete same-parent
cleanup entry. Every cleanup has state ownership, and state roles stay distinct.

The handler must contain the exact final FuncInfo-load and frame-handler jump
form. Cookie-check calls are recognized only as their exact native function
symbol/record/form. The cookie itself is DATA; CRT function code and DATA have
separate roles. Unknown names/classes never become CRT by default. Other parent
CRT contracts require the frozen explicit symbol set and exact source class,
undefined function record and executable original identity; they remain unresolved
contracts. Generated DATA may reuse a typed parent DATA identity only for the
same physical symbol and original base, retaining every parent-field proof
digest. This does not establish a DATA type extent or adopt its storage.
All ordinary and generated fields preserve full symbol/offset/kind/
addend/original-target evidence and distinct proof-family labels.

Native/reference nonfields and every DIR32/REL32 field are checked independently
for parent, each code piece and entire state table. Original HIGHLOW coverage must
agree in both directions. Parent and helper spans must lie wholly in executable
ranges; state metadata cannot overlap executable bytes. Source-associated helper
placement never establishes a runtime EBP, class/member role or function ABI.

## Expanded omission and SafeSEH accounting

The frozen ordinary result is retained verbatim by digest. Only exact physical
EH child, local-EH reference, same-parent-piece and selected SafeSEH obligations
explained by the new semantic graph are scoped; TLS, missing fields, labels,
unknown sections/directives, common/weak and other blockers remain blockers.
An arbitrary reason code cannot serve as an EH waiver.

All expanded runtime fields seed a new name/weak/directive closure. Undefined
conversion boundaries retain exact original identities. Every SafeSEH index is
decoded and validated, including unrelated registrations. Exactly the owned
handler is marked retained; omitted records must target sections and names
outside the expanded live closure. Missing, duplicate, auxiliary, foreign/live
or unregistered records fail closed. This establishes a proposed record-accounted
projection plan, not permission to copy or silently discard a mixed table.
No serializer is invoked by this collector. The separate readonly omission
adapter replays the original typed predicates and recomputes complete protection
under expanded roots before discharging an exact blocker ordinal/ID/digest.
Protected readonly data, BSS and LABEL obligations remain blocked.

Known other-parent diagnostics may remain in an otherwise matching selected
parent's context only when attributed to an exact recipe and verified-function
address. They are preserved, and strict whole-unit diagnostics remains false.
Selected-parent, foreign or unscoped errors block. This does not erase the
historical 95 notes or 128 false-piece observations.

## Actual collector source and gates

`parent_eh_collect.py` reads the one exact accepted lane-08 gzip stream and joins
record/certificate/contract hashes to the finite policy; it does not rescan the
global binding stream or workspace. It rehashes every exact requested source and
object, authoritative recipe/v3/selection, original reference/image-check file,
all semantic producers and optional-index state before and after publication.
The old ordinary certificate is freshly recomputed against each exact object.
Source hash context is recorded; historical compiler-header causality is not
invented or inferred from the wrapper source alone.

A scoped reference reader allows only each reviewed parent/matched-piece code
interval and bounded nonexecutable state metadata derived from its own handler's
FuncInfo field. Pinned parent literal comparisons may declare a complete native
literal extent up to 4,096 bytes, read-only and without storage adoption. Unknown
reads reject. Completed reads remain recorded if a later derived scope fails.
The unchanged image gate's sixteen probe ranges, PE headers and validated loader
HIGHLOW metadata are separate existing baseline checks; they are not broad target
code scans.

Bounds are 64 MiB raw objects, 256 MiB total declared section extent before the
unchanged parser materializes BSS, 64 KiB parent/helper code, 548-byte state
metadata, 4,096 fields/registrations, and per-parent 1 MiB/8,192 reference accesses.
The finite collection additionally enforces 540 seconds, practical 1 GiB peak
and 128 MiB compressed output. A leased root-coordinated slot is required before
any actual run. Outputs are exclusive, staged, compressed private metadata with
fsynced journals. Failed late publication removes only owned outputs while
preserving stage and failure evidence. This collector performs no compile,
link, COFF emission, native/Game execution or provider adoption.
