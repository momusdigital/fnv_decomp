# CODE59 and ModelLoader diagnostic successor

`application_wave8_diagnostic.py` prepares a separate response and full metadata
receipt. It does not invoke a native tool. The immutable V7 inputs are extended
by the accepted CODE59 archive and ModelLoader object: 60 function candidates
and 775 physical relocation fields. The complete candidate set is 14,405;
14,400 are ordinary prepared functions. All 45,315 fields are retained.

The ModelLoader adapter preserves both three-record undefined groups and their
six separate relocation/source-entry proofs. No record coalescing or logical
CODE alias by address is permitted. IOTask, additional CODE batches and the
blocked DATA bridge are outside this fixed cohort.

Ten new IAT fields retain their original compact witnesses and full original
proof payloads. The proof hashes, physical fields, original catalog identities
and derived annotations are verified independently. A temporary revalidated
census view restores tags for the existing 27-cell policy; the published field
ledger remains unchanged. Five new uses belong to those existing candidates;
five uses of four other cells remain unaliased. There are 409 IAT fields overall.

Only the four prior CRT aliases are candidates, with the full refreshed census
and coupled cookie policy. Every inherited IAT/CRT token is removed before its
new enabled subset is appended. The selected normal LIBCMT identity must match
each CRT provider. No new frame-handler or RTTI alias is added.

All exact source/native/proof/CRT artifacts and accepted reviews are bound
before preparation and rechecked afterward. A later separately reviewed,
CPU-leased driver may invoke LINK once and retain a compressed full native
receipt to stay within the unchanged 128 MiB output budget. Compression does
not omit fields, diagnostics, provenance or unresolved obligations.

The normal Windows x86/SP1 LINK policy, default CRT, failure classification and
prohibition on executable launch remain unchanged. Link success alone would
not establish Game ABI, object lifetime, EH/RTTI state, initializer coverage or
runtime readiness. Lazy archive candidates are not proven extracted members.
