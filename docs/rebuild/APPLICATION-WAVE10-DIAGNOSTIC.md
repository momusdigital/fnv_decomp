The four CRT bindings require a refreshed 45,947-field contract, expected 202 unchanged uses, normal library ancestry, and fresh strong-definition collision checks. The coupled cookie pair fails closed. No frame-handler or RTTI alias is introduced.

The response changes only output destinations, one additional archive, and the reviewed enabled alias subsets. It retains the selected library paths and normal SP1 x86 GUI CRT startup. Independent source/input, full-field, prepared-response, native-driver and CRT specialist gates precede one coordinator-leased diagnostic LINK. There is no custom entry point, FORCE, ignored errors, whole-DATA bridge, IOTask adoption, fake provider or executable launch.

A failed link preserves complete errors, warnings, provenance, library-search observations and a delta against V9. Unexpected success is not playable proof.
