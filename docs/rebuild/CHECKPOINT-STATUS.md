# Source-only rebuild tooling checkpoint

This is an experimental tooling checkpoint based on the existing reference-source repository. No complete source-built game executable or playable build has been demonstrated. The reviewed V10 application link diagnostic failed with 932 unresolved groups; the later reviewed V11 diagnostic failed with 929, and V12 failed with 928. These counts are diagnostic frontiers, not a percentage complete. Runtime provider, ABI, data, exception-handling, initialization and startup closure remain open.

This source/test/documentation set includes independently reviewed synthetic readiness, resource-source, RTTI and COFF-directive tools plus completed source-only relocation, callback and EH-related tooling. The existing matching recipe and reference oracle remain separate. Private game files, assets, executables, object files, disassembly, compiler installations and private receipts are not included. The root LICENSE remains unchanged; this checkpoint makes no new rights or redistribution claim.

Several historical projection and diagnostic tools require specific private, hash-bound build evidence, compiler/toolchain files and coordinator reviews that are not distributed in this checkpoint. In particular, the synthetic RTTI `*_once.py` runners are tied to the original private coordination/lease state and are not portable fresh-clone commands. The published source and synthetic tests can be inspected independently; reproducing a native operation needs a newly prepared, reviewed local setup. Do not publish the private inputs or receipts to make a command run. The ordinary reference comparison separately requires the personally owned compatible image described in the root README.

The following standalone synthetic suites were rerun against the working candidate: runtime-readiness 112 passed / 1 skipped, resource-source 89 / 1, RTTI ABI 96 / 0, RTTI runtime 165 / 1, and COFF directives 113 / 0. The skips require Windows symlink creation permission. Earlier synthetic RTTI compile/link and fixture runs are narrow evidence for that fixture only, not game startup or gameplay. Ten focused synthetic wave and dependency suites were also rerun: all 85 tests passed. Other groups retain their own reviewed test evidence. A bounded selected-file dependency and privacy review was completed; it does not establish that every possible dependency or sensitive item was identified.

Run the five suites with `python -m unittest discover -s tests/<group> -p "test_*.py"`, using `runtime-readiness`, `resource-source`, `rtti-abi`, `rtti-runtime-probe` and `coff-directives` for `<group>`. Do not execute a game or run native build probes as part of these synthetic checks.
