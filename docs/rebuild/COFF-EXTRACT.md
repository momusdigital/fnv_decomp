# Narrow zero-relocation COMDAT extraction

`tools/rebuild/coff_extract.py` implements the explicitly authorized first selection case: one already verified, whole-function code COMDAT with **zero runtime relocations**. It is not a general COFF linker, EH extractor, arbitrary section stripper or automatic provider selector. Original retained objects, source and comparison inputs remain untouched.

The caller supplies exact input/output/receipt paths, the authoritative recipe and retained manifests, a SHA-pinned retained verification receipt, an explicit recipe identity and a selected function symbol. The verifier receipt must have full authoritative scope, passing retained/function-byte/original-parity/global-listed-EH flags, an exact object hash and an actual per-function native entry proof. Local EH diagnostics in the selected provider reject extraction. Recipe reconciliation and current source/object observations are checked again. Merely appearing in a metadata address binding or passing another function in the same object is insufficient.

Input must be normal i386 COFF accepted by the strict parser. The selected native section/value/size must equal the proof, start at zero and fill the entire section. A unique external function and its ordinary section-definition symbol must be the only primary symbols in that section. Shared sections, extra local symbols, root auxiliary records not understood by the tool, associative roots, missing/unknown COMDAT policies or any root relocation fail closed.

All associative descendants are traversed. A non-debug/executable child, including EH or unwind material, rejects the operation. Debug-only descendants can be explicitly dropped, with their section/size/relocation/association recorded in the receipt. The reviewed native leaf's child is `.debug$F` section 14, containing one DIR32NB debug reference back to the leaf; it is dropped as debug metadata, not misclassified as runtime code. Standalone debug metadata is also explicitly listed as dropped. Cyclic associations reject. Initial scope permits only unrelated independent `.text` COMDATs and ordinary debug metadata outside the selected root; EH/data/TLS/initializer/unknown runtime sections reject rather than being silently removed.

The original `.drectve` is retained byte for byte only when its complete understood directives are the static `LIBCMT` and `OLDNAMES` defaults. Unknown `/INCLUDE`, export, entry, library or other linker requirements are not suppressed. The output rebuilds a valid two-section standard COFF object containing those directives and the selected code, with a section-definition auxiliary record and one external function. It rebuilds file offsets, section numbers, symbol indices and the string table. Code payload, section characteristics/alignment encoding and COMDAT selection policy remain unchanged; no machine instruction or relocation is synthesized. There is no runtime relocation to remap in this supported case.

The output is staged and independently reparsed using the inventory parser before exclusive publication. The receipt binds the retained proof, original/new object hashes, original function entry, selection and complete drop ledger. Failure cleanup removes only new artifacts owned by the operation. Consumers must require a complete receipt matching the output hash; two-file publication is not power-failure atomic. Existing outputs and evidence inputs are never overwritten.

## Actual proof and boundary

The private native proof selects recipe `0000-674cf48524ad6cf3`, function `0x00be0b90`, original section 13/value zero/size four, from input object SHA-256 `4c82eab96222de5e1494f2cedafcfe5f09d727c364e3cbd93d267ad63e14fc39`. The final retained v3 receipt contains the exact matched function/native entry and object identity. The selected output SHA-256 is `feb985c7279b6a78674e11d8b6060886ce497f27dfd38c92c1bb1b7cda458293`. The selected function remains four bytes with zero runtime relocations and unchanged characteristics/payload hash. Other independent game COMDATs and debug metadata are explicitly omitted; no fake provider was introduced.

The copied selected definition was then renamed with the separate one-symbol writer to the original fixture's typed method. Unchanged reference comparison logic accepted the extracted/renamed body: **match, four bytes, zero relocations, zero differences** against the same SHA-bound owned image. Normal VC9 CRT linking succeeded; independent validation reviewed the selected object, retained proof, linked payload, map, imports and absence of game initializers before execution. See [game leaf probe](GAME-LEAF-PROBE.md) for the bounded runtime result and preserved earlier whole-object failure.

Eight synthetic tests cover round-trip payload/characteristics/policy/directive preservation, runtime relocation and shared-section rejection, non-debug associative/EH rejection, explicit debug drops, unknown directives/TLS, malformed and unsupported records/invalid symbol references, proof-hash/input-output collisions and exclusive output protection. Run `python -m unittest discover -s tests/rebuild -p test_coff_extract.py -v`.

No general runtime/data dependency traversal, EH preservation, initializer scheduling or game-class consolidation is implemented. A function with runtime relocations or non-debug associative closure needs a separately specified, reviewed implementation. Successful extraction and a fixture execution do not establish game link closure or playability.
